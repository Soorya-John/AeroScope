METHOD

How findings work

Findings are generated from explicit thresholds and recorded evidence. They identify patterns to review; they do not confirm component faults or predict whether a vehicle is safe to fly.

VibrationLive screening threshold: 30 source units. Source scale and firmware interpretation can differ.
Battery behaviorShows measured voltage, current, and reported remaining percentage. Voltage sag alone cannot diagnose a battery.
GPS and estimatorReported state and logged messages are correlated in time. Temporal correlation does not establish causality.
Telemetry gapsA missing interval in the log may be a logging or sampling gap; it does not prove the aircraft link was lost.

MAP CONFIGURATION

Map style

The live position view currently uses an offline coordinate plot. Public tile services are not loaded by default. A future MapLibre style URL can be documented here; no paid API key is bundled.

Local-first storageFlight logs and SQLite data are stored in the project data/ directory by default. Configure AEROSCOPE_DATA_DIR to move them. Nothing is uploaded automatically.
